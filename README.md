# 越前海岸盛り上げ隊 (WordPress Theme)

越前海岸盛り上げ隊 のためのオリジナルテーマ  
[QWEL-TWO](https://github.com/qweldesign/qwel-two) から派生  

福井県福井市越前海岸エリアで町づくり活動を行っている団体のwebサイト  
20余りの観光関連の事業所を紹介しつつ, 町づくりの取り組みを紹介する内容  

2020年4月から運用開始し, 数回のリニューアルを繰り返しつつ,  
2026年1月現在に至るまで, 運用を継続  
安定運用に入ったので, テーマに関しては開発終了としアーカイブ  

[https://discoverechizen.com/](https://discoverechizen.com/)
